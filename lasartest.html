Läsartest i kaijsiska

Kan du översätta åt meningar utan hjälp?

Kaijsiska är ett konstruerat språk. Appendix C beskriver alla regler. Den här sidan är ett test på hur väl reglerna håller — både för dig som läsare och för språket som system. Kan du, med Appendix C som referens, lista ut vad meningarna betyder?

Så gör du

  1. Läs varje mening i kaijsiska (med fonetisk hjälp)
  2. Försök lista ut betydelsen med hjälp av Appendix C
  3. Klicka "Visa facit" när du är klar med meningen (eller ger upp)
  4. Sätt 1–5 beroende på hur säker du var: 1 = gissade helt · 2 = hade delvis rätt · 3 = förstod principen · 4 = nästan rätt · 5 = exakt rätt utan facit
  5. Totalsumman visas längst ner
